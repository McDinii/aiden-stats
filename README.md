# aiden-stats

Статическая страничка с аналитикой того, как я общаюсь со своим личным
Telegram-агентом. Открывается как Telegram WebApp прямо из бота.

**Что здесь есть:** только агрегаты — счётчики сообщений, распределение по дням
и часам суток, streak, статусы задач, топ обезличенных слов.

**Чего здесь нет и не будет:** текстов сообщений, имён, идентификаторов чатов,
названий проектов и компаний, любых ключей и токенов. Страница собирается
скриптом, у которого зашит фильтр: имена собственные и мат в облако слов не
попадают, а сборка падает, если в HTML найден хоть один секрет или путь.

Пересобирается автоматически каждую ночь. Графики нарисованы руками в SVG,
внешних зависимостей нет.
